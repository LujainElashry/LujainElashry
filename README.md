### 🍕 **PERFETTO Pizza – Full-Stack MERN Application**

> A complete pizza ordering platform with **real-time tracking**, **admin analytics**, and **secure authentication**.

[🌐 **Live Demo**](https://perfetto-pizza.vercel.app/) • [💻 **Source Code**](https://github.com/LujainElashry/perfetto-pizza)

---

### ✨ **Overview**
PERFETTO Pizza is a full-featured web application designed for a seamless customer experience and efficient order management.  
It allows users to browse menus, customize orders, and track delivery status in real time — while providing admins with a dashboard for performance analytics and inventory management.

---

### ⚙️ **Key Features**
- 🔄 Real-time **order tracking** system  
- 📊 **Admin dashboard** with analytics & metrics  
- 🧩 Menu management with **CRUD** operations  
- 🔐 **JWT authentication** and role-based access  
- 💬 **Customer messaging** & notification system  
- 📱 Fully **responsive** modern UI/UX design  

---

### 🧠 **Tech Stack**
**Frontend:** React.js, React Router, Axios, Context API  
**Backend:** Node.js, Express.js  
**Database:** MongoDB, Mongoose  
**Auth:** JWT, bcrypt  
**Cloud:** Cloudinary, Vercel, Render  

---

### 🎯 **Project Goals**
To combine **modern design**, **real-world scalability**, and **clean architecture** while providing an intuitive digital restaurant experience.  
This project reflects my focus on **usability, performance, and full-stack proficiency**.
